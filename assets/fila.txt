Você é o Engenheiro de Áudio do Guitar Studio. Nossa missão é substituir o som de sintetizador nativo do Python ("beep") por um motor de SoundFont (.sf2) profissional executado via pyfluidsynth.

Execute as seguintes tarefas rigorosamente para acoplar o motor ao nosso Desktop:

## TAREFA 1: O Script de Download e Setup (Engine e SoundFont)
1. Crie um script PowerShell `scripts/instalar_sf2_desktop.ps1`.
2. O script deve:
   - Baixar o pacote oficial do FluidSynth para Windows (https://github.com/FluidSynth/fluidsynth/releases/download/v2.3.4/fluidsynth-2.3.4-win10-x64.zip).
   - Extrair os arquivos (.dll e .exe) na nova pasta `assets/bin/fluidsynth/`.
   - Baixar o arquivo `sonivox.sf2` (https://cdn.jsdelivr.net/npm/@coderline/alphatab@latest/dist/soundfont/sonivox.sf2) para a pasta `assets/audio/soundfonts/`.
3. Adicione `pyfluidsynth` ao `requirements.txt` do ambiente desktop (se existir) ou instrua o usuário a instalar via pip.

## TAREFA 2: O Motor de Áudio Python (sf2_synth.py)
1. Crie o arquivo `audio/sf2_synth.py`.
2. REGRA DE OURO DO WINDOWS: Antes de importar `fluidsynth`, o arquivo DEVE injetar a pasta `assets/bin/fluidsynth/bin/` no `os.environ["PATH"]` para que o Python encontre a `fluidsynth.dll`.
3. Crie uma classe `GuitarSynth` que:
   - Inicialize o `fluidsynth.Synth()` e o `fluidsynth.Sequencer()`.
   - Carregue o arquivo `sonivox.sf2`.
   - Tenha um método `tocar_nota(corda, casa, duracao_ms)`.
   - Mapeamento MIDI Obrigatório (7 Cordas Padrão):
     * Corda 7 (B1) = MIDI 35
     * Corda 6 (E2) = MIDI 40
     * Corda 5 (A2) = MIDI 45
     * Corda 4 (D3) = MIDI 50
     * Corda 3 (G3) = MIDI 55
     * Corda 2 (B3) = MIDI 59
     * Corda 1 (E4) = MIDI 64
     A fórmula será: nota_midi = valor_da_corda + casa.

## TAREFA 3: Integração na Interface de Tablatura
1. Localize o módulo da interface Desktop onde o usuário clica ou digita as notas na grade da tablatura (Pygame ou Tkinter).
2. Substitua a função antiga que emitia o "beep" por uma chamada assíncrona/em thread ao nosso `GuitarSynth.tocar_nota(corda, casa)`. O áudio deve tocar imediatamente ao inserir o número.

Mostre a confirmação das integrações feitas.
